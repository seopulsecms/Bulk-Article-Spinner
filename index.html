Bulk Article Spinner

Masukkan artikel berformat spintax, tentukan jumlah variant, dan langsung download hasilnya sebagai file Excel.

Input Spintax
Format dasar: Gunakan {opsi1|opsi2|opsi3} untuk variasi teks.

Contoh sederhana:
{Saya|Aku} {suka|cinta} {kucing|karnivora}

Nested (bertingkat):
{Belajar {Python|JS}|Main {Gitar|Piano}}

HTML diperbolehkan:
<h2>{Judul A|Judul B}</h2>
<p>{Paragraf 1|Paragraf 2}</p>

Parser mendukung nested spintax tanpa batas kedalaman.
